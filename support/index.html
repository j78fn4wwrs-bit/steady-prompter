Can't connect? Check these four

Check them on both devices: the one showing the prompter and the one you're using as the remote. Remote pairing is a Pro feature, and only the prompter device needs Pro.

  • Allow Remote is on

    Open the Remote capsule on the prompter device. If the remote says "Looking for prompters…", turn Allow Remote on.

  • Devices are close

    Keep both devices nearby and on the same Wi-Fi network, and allow Local Network access for Steady Prompter.

  • Re-enter the code

    Type the 4-digit code again on the remote device.

  • App is up to date

    Update Steady Prompter on both devices.

Remote troubleshooting

  • "Looking for prompters…"

    Turn on Allow Remote on the prompter, keep both devices nearby on the same network, and re-enter the 4-digit code.

  • Navigate / Edit Script greyed out

    They only work while paused. Pause the prompter first.

  • Marker or edit buttons do nothing

    Update Steady Prompter on BOTH devices, then pause the prompter.

  • Remote shows "Disconnected"

    Turn Wi-Fi back on with the Remote screen open. It reconnects by itself, no code needed.

  • "Script was changed" alert

    Tap Reload to get the latest text. Edits made on the remote are lost.

  • Bought Pro before?

    Tap Restore Purchase on the paywall or in the menu at the top left of the script list, using the same Apple ID.
